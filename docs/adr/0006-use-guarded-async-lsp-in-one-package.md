# Use guarded async-lsp in one package

`lspc` will be one Cargo package whose main executable also runs its hidden background-owner mode. The session module will use `async-lsp` for JSON-RPC correlation, routing, cancellation, and server callbacks, with its dynamic forwarding support preserving arbitrary raw method names and JSON values. An `lspc`-owned framing guard will enforce header and body limits before bytes reach `async-lsp`, because the crate's private framing code is not sufficiently bounded or strict. This avoids maintaining a complete JSON-RPC dispatcher or an internal crate workspace while keeping the protocol contract and safety limits under `lspc`'s control.
